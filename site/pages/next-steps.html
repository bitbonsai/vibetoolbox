Your Mac is ready.

Ten minutes of orientation and you are off. Everything below assumes a fresh Ghostty window.

1. Open a fresh terminal

Your shell config only loads in new windows. Open Ghostty (or your terminal of choice) and you should see the Starship prompt: a clean line with your folder and git branch. Try:

ls        # pretty file listing with icons (eza)
z dev     # jump to ~/dev from anywhere (zoxide)
lt        # tree view of the current folder

2. Connect your AI agent

The agents you installed need an account to think with. Three routes:

  • You already have a subscription. Claude Pro or Max unlocks Claude Code: run claude and sign in. A ChatGPT plan unlocks Codex: run codex and sign in.
  • No subscription, one bill. OpenCode offers its own plans with model access included: run opencode and follow the sign-up.
  • All models, pay per use. Create an OpenRouter key. Pi, Crush, and OpenCode all accept it, and you can switch models freely.

Whichever you picked, the alias c starts Claude Code with sensible permissions when it is installed.

3. Make your first thing

cd ~/dev
mkdir my-first-site && cd my-first-site
c         # or opencode, codex, pi, crush

Then just describe what you want: "make me a single-page site about my dog, dark theme, big type." Watch it work. Ask for changes. That loop is the whole game.

5. Good to know

  • Re-run your install command any time. It is a system check that fixes only what is missing.
  • Updates run weekly (Mondays, 10:00) in the background. Log: ~/.vibetoolbox-update.log
  • Want more tools later? Go back to the picker, adjust, paste the new command.
  • Remove the toolbox config with --uninstall. Your tools and projects stay.
