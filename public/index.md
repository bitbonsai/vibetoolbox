# Vibe Toolbox

Open-source macOS environment installer for designers and PMs learning to code. Pick your tools, paste one command, start building.

- **Free and open source, for Mac.** AI coding agents, a cool terminal, editors. Ready in minutes.
- Selection is mandatory: tick tools in the picker (or start from a preset: Essentials, Recommended, Everything), copy one command, paste it in Terminal.
- The command encodes your exact selection as a short content-addressed link. Same selection = same URL, easy to save or share.
- Dependencies come along automatically (tools that need Bun pull Bun in).
- Re-running the same command is safe: it only fixes what is missing.
- Updates itself weekly.
