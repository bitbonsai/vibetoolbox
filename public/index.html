A box of the good stuff: modern terminal, AI coding agents, editors, and the small CLI comforts that make the command line feel like home. Built for designers and PMs. Free and open source.

Start from a preset:

or pick tool by tool below. Your command updates as you go.

How it works

  1. 1

    Tick the tools you want. Dependencies come along automatically.

  2. 2

    Copy your command. It encodes your exact selection in a short link.

  3. 3

    Paste it in Terminal, press Enter, and answer the occasional password prompt. Everything else is automatic.

  4. 4

    Re-run the same command any time. It checks your setup and fixes only what is missing.

A weekly background update keeps Homebrew packages, global packages, and Claude Code fresh. Remove everything with install.sh --uninstall. Tools stay, config goes.
